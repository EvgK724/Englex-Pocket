# Публикация Englex Pocket

Рабочий адрес: <https://evgk724.github.io/Englex-Pocket/>.
Источник Pages — GitHub Actions, основная ветка — `main`.
Переносить проект в новый репозиторий для обновления не нужно.

## Очередь публикации

1. В `main` попадают новые карточки и их примеры либо изменения приложения.
2. `Prepare generated Microsoft Ryan recordings` дополняет отсутствующие записи
   слов, затем примеров. Промежуточные коммиты сохраняют выполненную работу.
3. Когда все текущие карточки и примеры имеют соответствующую запись Ryan,
   генератор запускает `Publish Englex Pocket`. Это отдельный запуск: обычный
   коммит от `GITHUB_TOKEN` сам по себе не запускает другой workflow.
4. Публикация ещё раз проверяет словарь, исходные данные, все примеры и MP3.
   `prepare-pages.mjs` собирает `.pages-site`, после чего Pages размещает сайт.

Если запуск публикации начался до окончания синтеза, подготовка сообщит число
ожидаемых записей, а шаг размещения сайта будет пропущен. Уже опубликованное
приложение продолжит работать. После полного
синтеза очередь снова запускает публикацию. При ошибке сервиса генерация
останавливается с отчётом; не переключать голос и не ослаблять проверки.

Очередь ограничена по времени и числу продолжений. Продолжение разрешается только
после продуктивного запуска, остановленного собственным лимитом времени.
Не создавать параллельную очередь: повторный ручной запуск нужен только после
устранения ошибки либо для оставшейся работы за пределами этих лимитов.

## Аудио и размер сайта

В Git сохраняются все прежние файлы и индексы. В публикацию входят текущие
записи Ryan, приоритетные оригиналы Englex, актуальные записи примеров и
небольшие образцы, прямо используемые отдельными страницами прослушивания.
Неиспользуемые архивные библиотеки остаются в Git. Сборка останавливается,
если размер подготовленного сайта достигает 950 MB.

Файл примера содержит ID карточки, хеш английского текста и версию профиля Ryan.
Изменение предложения создаёт новый путь MP3; прежняя запись не перезаписывается.
Приложение не включает динамик, если запись относится к другой версии текста.

## Подтверждение результата

Успешный коммит не подтверждает выпуск. После Actions проверить публичные
`dictionary.json`, `examples.json`, индексы аудио и версию приложения; затем
открыть карточки разных типов, проиграть слово и пример и проверить сохранённые
отметки. Для изменений интерфейса дополнительно проверить WebKit, узкий экран
и увеличенный текст. Данные закрытого аккаунта Englex в Pages не публикуются.

Использование на iPhone и перенос прогресса описаны в [README.md](README.md).
