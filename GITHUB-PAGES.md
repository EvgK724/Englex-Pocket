# Englex Pocket на GitHub и iPhone

В пакете — все 8 132 исходные карточки и 8 132 готовые записи AI Voice, новая иконка, мобильное оформление и автоматическая публикация. Генерация озвучки или платный API для запуска не нужны.

## Сохранить в существующем репозитории

Удобнее один раз выполнить перенос на компьютере с GitHub Desktop:

1. В GitHub Desktop войдите в свой аккаунт и клонируйте уже созданный репозиторий Englex Pocket: **File → Clone repository**.
2. Распакуйте `Englex-Pocket-GitHub.zip`. Скопируйте содержимое папки `Englex-Pocket` в папку клонированного репозитория. Папки `dist`, `scripts` и `.github` должны оказаться в корне репозитория; `.github` может быть скрыта файловым менеджером.
3. Проверьте изменения в GitHub Desktop, сделайте **Commit**, затем **Push origin**. Существующие посторонние файлы и настройки репозитория удалять не нужно.

Сам ZIP в репозитории не запускается: нужны распакованные файлы. В пакете более 8 000 небольших аудиофайлов, поэтому перенос папки через GitHub Desktop удобнее веб-загрузки по одному файлу.

## Получить ссылку на приложение

1. Откройте свой репозиторий на сайте GitHub → **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте **Actions → Publish Englex Pocket → Run workflow** на основной ветке репозитория.
4. После успешной публикации адрес приложения появится в **Settings → Pages** и в результате запуска. Открывайте именно эту ссылку, а не страницу файлов репозитория.

Последующие изменения `dist` на основной ветке `main` или `master` публикуются автоматически. Для другого имени основной ветки используйте **Run workflow** или добавьте её в список `branches` файла `.github/workflows/pages.yml`.

Обычный GitHub Pages публикует содержимое приложения в интернете, в том числе если исходный репозиторий приватный. Избранное и личные отметки остаются в браузере и в репозиторий не передаются. Приватная публикация Pages доступна для соответствующих организаций GitHub Enterprise Cloud. На GitHub Free Pages доступен для публичных репозиториев; не меняйте видимость существующего репозитория, если хотите оставить исходники личными.

[Настройка Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), [официальный workflow](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [доступ к приватному Pages](https://docs.github.com/enterprise-cloud%40latest/pages/getting-started-with-github-pages/changing-the-visibility-of-your-github-pages-site).

## Добавить на экран iPhone

1. Откройте ссылку приложения в **Safari**.
2. Нажмите **Поделиться**; в некоторых вариантах панели Safari эта команда находится в меню **Ещё**.
3. Выберите **На экран «Домой»**, включите **Открывать как веб-приложение**, если такой переключатель показан, и нажмите **Добавить**.

На экране появится тёмная иконка Englex Pocket с золотой буквой `e`. При запуске с неё карточки открываются как отдельное приложение. Поиск и фильтры доступны по кнопке лупы; голос и темп — по кнопке настроек. Кнопка динамика стоит рядом с английским выражением с обеих сторон.

Предусмотрены безопасные отступы под Dynamic Island и нижнюю полосу жестов, портретный и альбомный экраны iPhone Pro Max. Длинный текст может прокручиваться; масштабирование текста не блокируется.

[Инструкция Apple](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios).

## Перенос прогресса

На старом адресе откройте настройки → **Сохранить копию прогресса**. На новом адресе — настройки → **Восстановить из копии**. Отметки и избранное добавятся к уже имеющимся. Прогресс сохраняется отдельно для каждого адреса и браузера; автоматической синхронизации нет. Если Safari и установленное приложение показывают разный прогресс, восстановите копию внутри приложения.

Для открытия словаря и загрузки аудио нужен интернет. MP3 загружается только при нажатии на динамик: все записи сразу на телефон не скачиваются.
