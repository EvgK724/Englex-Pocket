# Englex → Pocket: синхронизация

Репозиторий публичный. Пользователь разрешил публикацию новых записей с исходными
переводами. Не переносить пароли, cookies, токены, профиль, переписку и уроки.
Публикация main использует существующий GitHub Pages workflow.

## Перенос записей

1. Читать текущие scripts/import-englex.mjs, scripts/dictionary-integrity.mjs
   и dist/dictionary.json. Если большой файл вернулся пустым, использовать
   его актуальный SHA и github_fetch_blob.
2. Через control-browser открыть Englex → «Словарь» → «Весь словарь».
   Вход — только через защищённый browserAuth. Читать DOM, не скрытые API.
3. Читать весь период начиная с предыдущего дня относительно metadata.through,
   включая последнюю дату импорта целиком. Подгружать старые строки прокруткой
   вверх до более ранней даты или настоящего конца списка. 20 строк недостаточно.
   Первичная историческая граница — 2026-09-05; более старые слова не импортировать.
4. Временный JSON-массив: {word,translation,ipa,kind,added,lists}.
   added — действительная дата Englex в YYYY-MM-DD, не дата проверки.
   «Сегодня» сопоставлять с календарём страницы. Неизвестные ipa/lists — "".
   kind — word/collocation/phrasal: классификация приложения, если её нет в Englex.
   Перевод сохранять без исправлений, включая опечатки; IPA не выдумывать.
5. На актуальной версии выполнить:

   ```sh
   node scripts/import-englex.mjs /path/to/englex-new-words.json
   node --test scripts/test-import-englex.mjs
   node scripts/check-static.mjs
   ```

Импорт дописывает карточки и сохраняет все прежние данные и IDs. Нормализованный
повтор «слово + перевод» пропускается, другое значение сохраняется и отмечается.
metadata.through — максимальная дата карточек, не дата проверки.
При changed:false коммит не нужен. При конфликте перечитать main и повторить
слияние без force push. Проверить Actions/Pages и приложение: коммит сам по себе
не подтверждает публикацию. Неполный охват прямо обозначить.

## Единственная озвучка — Ryan

24 сентября 2026 года пользователь выбрал только Ryan для текущих и будущих
карточек. Прежние Choni/Doris настройки переходят на Ryan; прогресс, избранное,
карточка, фильтры и темп сохраняются. При отсутствии записи динамик недоступен:
скрытой подмены другим голосом нет.

Профиль: Microsoft Edge TTS, британский мужской en-GB-RyanNeural, обычные
rate/pitch/volume, MP3 24 kHz / 48 kbps, edge-tts==7.2.8.
20 сентября пользователь прослушал образец, подтвердил совпадение с Englex и
разрешил передачу Microsoft/Bing только английского текста текущих и будущих
карточек для дополнения озвучки. Переводы и данные аккаунта не передаются.
Источники проверки — docs/englex-ai-source.md.

Оригиналы dist/englex-ai-index.json и dist/audio/englex-ai/ сохраняются и имеют
приоритет. Синтез хранится отдельно: dist/englex-ryan-index.json,
provider Microsoft Edge, source generated, voice en-GB-RyanNeural,
файлы dist/audio/englex-ryan/. Не выдавать синтез за скачанный оригинал.
Перед дополнением читать .github/workflows/englex-ryan.yml и
scripts/generate-englex-ryan.py. Изменение dictionary.json автоматически
запускает заполнение отсутствующих записей. Не дублировать активную очередь.
При ошибке выяснить причину: не отключать TLS, не обходить ограничения,
не менять голос и не переходить на платную модель.
Продолжение ограничено контрактом workflow и возможно только при прогрессе.

Даже без новых слов проверять union ID двух Ryan-индексов по последнему словарю,
наличие реальных MP3 и успешную Pages-публикацию. Отчёт генератора относится к
снимку начала запуска: перед полной готовностью сверить актуальный main.
Незавершённую озвучку отличать от уже опубликованных карточек.

### Оригиналы Englex

Оригиналы с пометкой AI можно сохранять через подтверждённый интерфейс браузера,
точно сопоставляя текст строки и владельца плеера. Не переносить сессию,
скрытые API, временные blob/HTTP URL, cookies или токены.
node scripts/import-englex-audio.mjs /path/to/captured-audio.json принимает
[{"word":"точный текст","file":"/path/to/original.mp3"}].
Пакет .englex-audio-import/batch.json:
{"version":1,"recordings":[{"word":"точный текст","audioBase64":"байты MP3"}]}.
Лимиты — 1000 записей и 20 MiB. Маркер коммита:
Import original Englex AI recordings [englex-ai-v1].
Существующий иной MP3 при конфликте не перезаписывать. Проверять слияние
с актуальным main и Pages. Исторический backlog неполон и не доказывает
отсутствия других оригиналов. Словарь/IDs ради аудио не изменять.

### Архив Choni и Doris

Все прежние MP3 и индексы сохраняются побайтово, включая recover, очищенные
производные, sourceBlobs и voiceOverrides. Их нет в выборе приложения,
и обычная синхронизация их не дополняет.
Изменение словаря и прежний accepted-маркер больше не запускают Fish.
Автоматическая очистка Choni отключена. Архивные инструменты оставлены
для явного отдельного ручного запуска, не для новых карточек.
Не запускать Fish, очистку или Doris без нового запроса пользователя.

## Обновление и уведомления

Приложение проверяет свежую коллекцию при запуске, возвращении на экран,
восстановлении соединения и раз в пять минут, пока открыто.
При ошибке уже загруженная коллекция сохраняется. Не обещать обновление
на устройстве до проверки поведения и публикации.

После добавления сообщить число, реальную дату охвата, 2–3 примера и ссылку.
При добавлении только аудио — один раз сообщить число и Ryan.
Если ничего не добавлено и проверка полная — не уведомлять.
При сбое назвать реальную причину; не говорить «новых слов нет»,
не заменять словарь пустым, не повторять одинаковое предупреждение.
