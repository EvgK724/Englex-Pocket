# Englex → Englex Pocket

Синхронизация добавляет новые записи личного словаря Englex в `dist/dictionary.json`.
Для мониторинга используется ежедневная задача ChatGPT в 23:45 (Asia/Yekaterinburg)
через авторизованный браузер;
этот репозиторий сам не входит в Englex и не хранит пароли, cookies или токены Englex.
Публикация `main` запускает существующий GitHub Pages workflow.

## Перенос записей

1. Открыть Englex → «Словарь» → «Весь словарь» в авторизованном браузере.
2. Читать английский текст, исходный перевод и дату из видимой таблицы. Список
   подгружает более старые записи при прокрутке вверх. Проверить весь период
   после предыдущего импорта, включая дату его последней записи: не ограничиваться
   первыми 20 строками. Первоначальная граница — 5 сентября 2026 включительно;
   историческую коллекцию до этой даты заново не импортировать.
3. Подготовить временный JSON-массив с полями `word`, `translation`, `ipa`, `kind`,
   `added`, `lists`. Дата — `YYYY-MM-DD`. Неизвестные IPA и списки — пустые строки.
   Категория приложения — `word`, `collocation` или `phrasal`; если Englex не
   показывает категорию, это наша классификация, а не данные источника.
   Не исправлять исходный перевод без отдельного запроса пользователя.
4. На актуальной версии репозитория выполнить:

   ```sh
   node scripts/import-englex.mjs /path/to/englex-new-words.json
   node --test scripts/test-import-englex.mjs
   node scripts/check-static.mjs
   ```

5. Если `changed` равно `false`, коммит не нужен. Иначе сохранить только результат
   импорта в GitHub и дождаться успешной публикации. При изменении ветки другим
   процессом повторить импорт на новой версии; не использовать force push.

Импорт сохраняет все существующие карточки и их идентификаторы, отбрасывает
повтор той же пары «слово + перевод», а новое значение уже имеющегося слова
добавляет отдельной карточкой и отмечает в отчёте. Обновления существующих
переводов и удаления из Englex автоматически не применяются. Проверка защищает
исходные 8 132 карточки и проверяет новые данные до публикации.

## На телефоне

Приложение запрашивает свежий словарь при запуске, возвращении на экран,
восстановлении соединения и раз в пять минут, пока оно открыто. Выбранная
карточка, избранное и прогресс сохраняются. При ошибке обновления уже открытая
коллекция остаётся доступной. В меню ровно три голоса: «Englex · AI»,
«Чонишвили · вариант A» и «AI Voice · мягкий голос». Выбор сохраняется для
всей коллекции; записи одного голоса не подменяются другим. Если запись выбранного
варианта отсутствует, приложение показывает это и предлагает выбрать другой голос.
Прежние записи AI Voice сохраняются.

## Озвучка

Пользователь выбрал вариант A для всей коллекции. Профиль `a-v1` использует
прежний Fish voice ID `089f2e853e064d6fb15f5b5882914b52`, только бесплатный
`s2.1-pro-free`, temperature `0.3`, cue `[Native British English pronunciation, clear neutral English vowels] `
и прежнюю обработку `--denoise`. Точная одобренная запись `recover` копируется
из варианта A без повторного синтеза. Файлы пишутся в `dist/audio/fish-chonishvili-a-v1/`,
индекс — `dist/fish-chonishvili-a-v1-index.json`.

Изменение `dist/dictionary.json` запускает подготовку только отсутствующих записей A.
Одноразовый запуск всей очереди: коммит начинается с
`Run Chonishvili A dictionary [fish-a-v1]` или workflow Fish, voice `a`, mode `full`.
Готовые записи публикуются порциями; продолжение после ограничения времени возможно
только при подтверждённом прогрессе, максимум восемь раз. Ошибки API, квоты,
авторизации или публикации не вызывают автоматического повтора и не включают платный engine.
Секрет Fish остаётся только в GitHub Actions. Старые MP3 и индексы сохраняются,
но старые голоса и экспериментальные пробы не предлагаются в интерфейсе.

Englex AI — только оригинальные записи, доступные через динамик с пометкой AI
в авторизованном личном словаре. Сохранить аудиофайл через доступный интерфейс
браузера; сопоставить точный английский текст с текущими карточками. Не использовать
скрытые API или перенос сессии. Временные `blob:` URL, cookies и токены не публиковать.
Временный локальный JSON: `[{"word":"точный английский текст","file":"/path/to/original.mp3"}]`.
Выполнить `node scripts/import-englex-audio.mjs /path/to/captured-audio.json`.
Он сопоставляет все значения точного слова, сохраняет текущие записи и сообщает конфликты;
существующие разные MP3 не перезаписываются. Неизвестные слова не создают карточек.
MP3 хранятся в `dist/audio/englex-ai/`, индекс — `dist/englex-ai-index.json`.
При синхронизации новых карточек сохранять доступную исходную AI-озвучку тем же
способом; отсутствие доступной записи не блокирует импорт словаря.
Покрытие каждого из трёх голосов отображается в приложении отдельно.


## Ошибки доступа

Если Englex завершил сеанс или не показывает словарь, не заменять коллекцию
пустыми данными и не сообщать «новых слов нет». Задача должна уведомить о
необходимости восстановить доступ. Вход выполняется через защищённую форму,
пароль не передаётся в чат или репозиторий.
