# Englex Pocket

[Открыть приложение](https://evgk724.github.io/Englex-Pocket/)

Личный словарь для повторения английского на iPhone и компьютере. В коллекции
8 473 карточки: слова, сочетания и фразовые глаголы. Исходные английские выражения,
переводы, даты и идентификаторы Englex сохранены. Последняя дата карточек в этом
снимке — 11 октября 2026 года; это не дата последней проверки аккаунта Englex.

## Как заниматься

1. Вспомните значение английского выражения и нажмите динамик, чтобы услышать Ryan.
2. Откройте перевод. Под ним расположен учебный пример уровня B1–B2 с отдельной
   кнопкой озвучки. Сначала попробуйте понять предложение самостоятельно.
3. При необходимости нажмите «Показать перевод примера». Если в исходном словаре
   обнаружена явная опечатка или неверный перевод, пояснение появится здесь же.
4. Отметьте «Повторить» или «Знаю», либо добавьте карточку в избранное.

Примеры созданы отдельно для обучения. Они не выдаются за оригинальный материал
Englex и не заменяют исходные поля карточек. Для слова и примера используется
Microsoft Ryan (`en-GB-RyanNeural`). Темп регулируется в настройках. Если загрузка
записи прервалась, нажмите тот же динамик ещё раз.

## На экране iPhone

Откройте приложение в Safari → «Поделиться» → «На экран “Домой”» → «Добавить».
Если показан переключатель «Открывать как веб-приложение», включите его.
Поиск и фильтры доступны по кнопке лупы, темп и копия прогресса — в настройках.
Карточки поддерживают узкий экран и увеличенный размер текста.

Для открытия словаря и загрузки MP3 нужен интернет. Записи загружаются при нажатии
на динамик; вся аудиоколлекция заранее на телефон не скачивается.

## Сохранённый прогресс

Избранное, отметки, текущая карточка, темп, фильтры и выбранная колода сохраняются
в браузере. При обновлении коллекции прежние отметки не удаляются, в том числе
если сначала загрузилась более старая версия словаря.

Настройки → «Сохранить копию прогресса» позволяют перенести отметки. На другом
устройстве выберите «Восстановить из копии»: отметки добавятся к имеющимся.
Между устройствами, браузером и установленным веб-приложением автоматической
синхронизации личного прогресса нет.

## Обновление коллекции и Ryan

Порядок импорта описан в [SYNC.md](SYNC.md). Новые записи добавляются без удаления
или переписывания прежних. Для каждой новой карточки одновременно готовится
учебный пример; он хранится в `dist/examples.json`, отдельно от словаря.

Изменения словаря или примеров в `main` запускают GitHub Actions. Очередь
дополняет отсутствующие MP3 слов и примеров, проверяет записи и сохраняет
промежуточные результаты. Готовая версия публикуется только после проверки
полного покрытия актуальной коллекции. Незавершённая генерация не заменяет
работающую версию сайта. Пароль Englex для синтеза и публикации не нужен.

Чтение новых слов из закрытого словаря Englex требует доступного авторизованного
браузера. Сохранённый вход на одном устройстве автоматически не переносится
в облако или на другое устройство. GitHub Actions не входит в аккаунт Englex.

## Проверка и публикация

```sh
node --test scripts/test-import-englex.mjs scripts/test-voice-options.mjs scripts/test-recorded-speech.mjs scripts/test-fish-voice.mjs scripts/test-search.mjs scripts/test-search-session.mjs tests/import-englex-audio.test.mjs scripts/test-examples.mjs scripts/test-example-ui.mjs
python scripts/test-englex-ryan.py
python scripts/test-example-ryan.py
node scripts/check-static.mjs --require-ready
node scripts/prepare-pages.mjs .pages-site
```

Python-проверкам нужен `ffmpeg`. Генератор использует `edge-tts==7.3.1`.
Подробности публикации — [GITHUB-PAGES.md](GITHUB-PAGES.md).
